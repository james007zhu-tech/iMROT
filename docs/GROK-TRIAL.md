# 试运行测试任务书（给 Grok）— iMROT「i」与「T」

目的：把每一条流程在真实界面上走一遍，找出卡住、出错、显示不对的地方。
**规则：跑通之前不做业务闭环。** 开票（TITH）、请款（IVTH）、回款、月度账单（BLTH）在系统里是关着的（`BUSINESS_CLOSURE=off`）。不要改成 `on`，不要绕过。

---

## 0. 准备（在本机 ~/src/imrot 或代码所在目录）

```bash
git pull
npm install
npm run db:push
npm run db:seed          # 已有数据也可以重跑
npm run fx:fetch         # 中国银行汇率
npm run trial:seed       # 生成两个试用账号，终端打印账号和密码
npm run dev              # http://localhost:3000
```

`.env` 里应有 `BUSINESS_CLOSURE=off`（不写也等于 off）。`trial:seed` 末行会显示 `Business closure … OFF`。
密码只在终端打印，不进代码库；忘了就再跑一次 `npm run trial:seed`，会换新密码。

## 4. T 模块：iMROT-T 原型

T 目前是独立原型页面（claude.ai Artifact「iMROT-T」），**没有登录和账号**，学员数据存在浏览器本地。它还不在本代码库里。
需要朱总先在页面的 Share 菜单里打开链接访问，或者在他已登录的浏览器里测。

逐个页签测：总览、能力图谱、学员与路径、入门诊断、排程、课程生成、专题、微课库、**能力测评**、微课、故障剧本、AI 导师、考核、人才交付。
能力测评重点：自适应出题是否按领域换题；「纯猜 / 不太确定 / 比较确定 / 非常确定」是否记录；过快作答是否标出；至少 5 道带危险选项的安全题；结果给出 L1–L4 各等级可能性和各领域标准误。
